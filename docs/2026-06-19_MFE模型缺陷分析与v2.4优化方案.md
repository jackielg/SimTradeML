# MFE 模型缺陷分析与 v2.4 优化方案

**日期**: 2026-06-19
**触发**: PTrade 2025 沙箱实测（ML 生效版）+ 本地 attribution 归因
**适用**: `examples/mfe_train_full.py`（macd_golden 策略用的 mfe_5d 模型）
**结论**: ❌ **v2.4 实验失败，整体 ML 改造收益天花板低，不达 +30~50% 目标**（用户要求：除非 ML 加入能提升 30~50%，否则没有意义）

**最终验证**（2026-06-19 晚）：
- v2.2.15 baseline（无 ML）2025 5m 本地 = **+142.45%**（来自 `docs/freq_scan_2026-06-18/scan_summary.md`）
- v2.3 (纯 MFE 标签) PTrade 沙箱 = +156.67%（仅 +14pp，TOP15 占 97% 集中度，风险换收益）
- v2.4 (MFE-MAE 标签) 本地 = **+107.40%**（-35pp，牺牲抓暴涨能力，治标不治本）
- **ML 改造失败**：选股链路候选池前置过滤已压缩，ML 仅末位微调，边际收益 < 15pp
- **根因误判**：原以为"熊市失效"是 ML 标签问题，实际是策略层面问题（候选池/选股逻辑/资金管理）
- **决策**：ML 改动归档保留，策略回退到 v2.2.15 baseline，走"人工分析回测输出文件"优化路径

**归档**：
- SimTradeLab 端：`strategies/macd_golden/ml_model_v2.4/`（v2.4 模型 + scaler + meta，3 JSON）
- SimTradeML 端：`examples/deploy_mfe_2023-12-31.{json,scaler.json,scaler.pkl,meta.json}`（v2.4 产出）
- 策略代码：`backtest.py` MLFilter.ML_ENABLED = False（默认关），代码完整保留便于以后启用

## 2. ML 四类缺陷（根因 → 证据）

### 缺陷 1: 标签无下行保护（根因）
- **现状**: `examples/mfe_train_full.py:114` `mfe=(fut_high-cur)/cur`，纯最大涨幅（用 high）
- **后果**: MFE 奖励任何"曾涨过"的股，不管之后暴跌。熊市选出暴涨后崩盘的股
- **证据**: 1-2月跑输基准 4-6pp（熊市满仓选股，无择时）

### 缺陷 2: 极端集中（致命）
- **现状**: ML 只排序不筛掉，策略槽位 3 + 满仓滚存
- **后果**: TOP15 占 97.1%，少数暴涨小盘股决定全部收益
- **证据**: 撤了 TOP15 整体即亏；TOP10 全靠单次 100% 胜率运气股

### 缺陷 3: 短持仓噪声交易
- **现状**: 1 天持仓 = -13.1 万拖累
- **后果**: ML 把不该买的排进来，T+1 即止损出局
- **证据**: 8-15 天持仓才正贡献

### 缺陷 4: 赢家靠运气非判断力
- **现状**: TOP10 盈利股全 100% 胜率单次交易小盘股
- **后果**: 非 ML 持续判断力，是统计噪声

## 3. v2.4 优化方案（按优先级）

### 方案 A: 标签改造（最高优先，治本，本子项目职责）
改 `examples/mfe_train_full.py:113-115`，三选一：

```python
# 方案 A1: 风险调整 MFE (MFE - MAE, 奖励上涨惩罚下跌) ★推荐
fut_high = h[end+1:end+1+PREDICT_DAYS].max()
fut_low  = l[end+1:end+1+PREDICT_DAYS].min()
mfe = (fut_high - cur) / cur
mae = (cur - fut_low) / cur
label = mfe - mae   # 净风险调整收益

# 方案 A2: 条件触发标签 (仅趋势市打分, 熊市标签置 0/负)
# 加入大盘状态: MA60 之上=趋势市, 标签=mfe; 之下=标签=mfe*0.3 惩罚

# 方案 A3: 收盘价实际收益 (非最高价幻想)
label = (fut_close - cur) / cur   # 用 ret 而非 mfe, 消除"触及但回落"
```
**推荐 A1**（MFE-MAE）：保留上涨激励但惩罚下跌，治熊市失效。需重训验证 IC（目标保持 0.25+）。

### 方案 B: 分散持仓（降集中度，治致命缺陷，SimTradeLab 策略层）
改策略集成（MLFilter.rerank 后 + 仓位管理）：
- 硬限单股权重 ≤ 15%（当前 TOP1 占 114%）
- 提高 top N（3→5-8），分摊资金
- TOP15 集中度目标 < 60%（当前 97.1%）

### 方案 C: 市场状态过滤（治熊市失效，SimTradeLab 策略层）
策略层加：`if 大盘 MA60 之下: ML 权重*0.3 或降仓`

### 方案 D: 持仓时长过滤（治噪声，SimTradeLab 策略层）
- 入场加最小持有期约束（≥2 天），过滤 1 天快进快出
- 或 ML 特征加"信号持续性"指标（本子项目 technical.py 注册）
